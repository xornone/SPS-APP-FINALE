Feuille de route · mise en ligne

De GitHub au club, en 6 étapes

Le code de l'app réelle (Next.js + Supabase) est déjà prêt sur github.com/xornone/sps-app. Cette page suit la mise en ligne comme une sortie club — chaque étape est un point de passage, coche-les au fur et à mesure. Ta progression reste dans ce navigateur.

Progression0 / 12

Base de données vierge par défaut — aucun membre ni sortie fictive n'est injecté par le schéma.

Déjà fait — dépôt GitHub public À créer — compte Supabase (gratuit) À créer — compte Vercel (gratuit)
1

Créer le projet Supabase

Base de données
  1. Sur supabase.com → New project — nomme-le par exemple sps-app, choisis une région proche (Europe) et un mot de passe de base de données (garde-le de côté, tu n'en auras pas besoin au quotidien).
  2. Laisse le provisioning se terminer (~2 minutes).
  3. Dans Project Settings → API, note l'URL du projet et la clé anon public — elles serviront à l'étape 3.
2

Appliquer le schéma

SQL

Dans Supabase : SQL Editor → New query, colle le contenu de supabase/migrations/0001_init.sql (dans le dépôt) puis Run. Ce fichier crée les tables (rides, ride_groups, participations, notifications), une vue publique ride_participants, les règles de sécurité (RLS) et le stockage GPX — rien d'autre. Il n'y a pas de table de comptes membres : participer à une sortie ne demande qu'un nom, saisi directement dans l'app.

Le fichier supabase/seed.sql est optionnel. Il ajoute seulement 3 sorties d'exemple, sans aucun membre fictif — l'app est déjà « vierge » sans lui. Exécute-le seulement si tu veux garder ces 3 sorties comme premier contenu, sinon passe directement à l'étape 3.
3

Déployer sur Vercel

Hébergement
  1. Sur vercel.com → Add New → Project → Import Git Repository, connecte ton GitHub si besoin puis sélectionne xornone/sps-app.
  2. Framework détecté automatiquement : Next.js. Root Directory : laisse ./ — l'app réelle est à la racine du dépôt (le prototype de démo vit à part, dans /prototype).
  3. Avant de lancer le déploiement, ouvre Settings → Environment Variables et ajoute :
NEXT_PUBLIC_SUPABASE_URL
L'URL du projet (étape 1)
NEXT_PUBLIC_SUPABASE_ANON_KEY
La clé anon public (étape 1)
SUPABASE_SERVICE_ROLE_KEY
Project Settings → API → service_role — secret serveur, ne jamais exposer côté client
NEXT_PUBLIC_SITE_URL
https://sps-app-xxxx.vercel.app (ajustable après le 1ᵉʳ déploiement, puis redeploy)

Deploy. Premier build : environ 1 à 2 minutes.

4

Autoriser les redirections

Auth

Dans Supabase : Authentication → URL Configuration.

Site URL
https://sps-app-xxxx.vercel.app
Redirect URLs
https://sps-app-xxxx.vercel.app/auth/callback

Sans cette étape, le lien reçu par email redirigera vers une URL refusée et la connexion échouera.

5

Créer ton compte administrateur

Un seul compte

L'app n'a qu'un seul compte : l'administrateur du club. Les membres n'ont besoin d'aucun compte pour participer aux sorties (étape 6) — inutile donc d'inviter qui que ce soit d'autre ici.

  1. Dans Supabase : Authentication → Providers → Email, désactive Allow new users to sign up. Cela empêche toute inscription publique — seul un compte que tu invites toi-même pourra se connecter.
  2. Dans Authentication → Users → Invite user, entre ton adresse email et confirme.
  3. Ouvre l'email d'invitation reçu (vérifie les spams — le tout premier envoi Supabase y atterrit parfois) et clique le lien.

Tu arrives connecté directement : comme il n'existe qu'un seul compte, toute session authentifiée est le compte administrateur — pas de rôle à activer séparément. L'onglet Administration est utilisable dès cette première connexion.

6

Faire rouler le club

Aucun compte membre

Les membres n'ont rien à créer ni à installer. Partage-leur simplement l'URL de l'app (celle de Vercel, ou ton nom de domaine si tu en ajoutes un plus tard) :

  1. Ils ouvrent l'app et vont sur la sortie qui les intéresse.
  2. Ils tapent leur nom, choisissent leur groupe (Vert / Rouge / Violet) et valident — c'est leur seule action, aucun mot de passe.
  3. Ils peuvent retirer leur propre participation à tout moment, depuis le même écran, en touchant leur inscription.

Toi seul, connecté en admin, peux créer, modifier ou supprimer des sorties. Le classement (onglet Classement) regroupe automatiquement les participations passées par nom déclaré.

Pièges fréquents

Les emails d'invitation ou de connexion n'arrivent pas

Le plan gratuit Supabase limite l'envoi d'emails d'auth à quelques-uns par heure — largement suffisant ici puisqu'il n'y a qu'un seul compte à inviter et à faire se reconnecter de temps en temps. Si besoin, un fournisseur SMTP externe peut être branché dans Authentication → Email Templates → SMTP Settings — pas nécessaire pour démarrer.

La connexion boucle ou renvoie une erreur

Vérifie que NEXT_PUBLIC_SITE_URL (Vercel) et les Redirect URLs (Supabase) pointent exactement vers la même adresse — présence du slash final et http/https compris.

Ajouter un nom de domaine personnalisé plus tard

Possible à tout moment dans Vercel → Settings → Domains (ex. app.spscycling.fr). Il faut alors remettre à jour NEXT_PUBLIC_SITE_URL et les Redirect URLs Supabase avec la nouvelle adresse.
